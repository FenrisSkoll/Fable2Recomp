baseline, three runtime harvests, and performance observations.

Suggested reading order:

1. [Verified baseline](fable2-fault-walker-baseline.md) — durable status and
   accepted conclusions through Harvest 003.
2. [Workflow](fault-walk.md) — current operating procedure and guardrails.
3. [Harvest 001](fault-walk-harvest-001.md),
   [Harvest 002](fault-walk-harvest-002.md), and
   [Harvest 003](fault-walk-harvest-003.md) — chronological run findings.
4. [Performance checkpoint](fault-walk-performance.md) — measured overhead and

The verified baseline is the current summary. The harvest files remain the
authoritative per-run records and must retain their exact addresses and results.
