## Coverage

Fully documented at the static-source level:

- plugin loading, ABI, initialization, shutdown and ownership;
- ring worker, packet decoding, registers, waits and interrupts;
- D3D12 versus shared/Vulkan build boundary; and
- configuration, diagnostics, fallback/error and device-loss structure.

Partially documented because runtime selection/title use is unknown or source
contains incomplete behavior:

- draw initiation, extents, topology, indices, queries and predication;
- vertex/texture fetch, formats, tiling, endian and samplers;
- EDRAM, depth/stencil, MSAA, aliasing, resolves and clears;
- shader translation and asynchronous/persistent caches;
- pipeline state, descriptors and constants;
- shared memory, uploads/readback, barriers, queues and fences;
- swap mailbox, host pacing and presentation; and
- bounded system-UI composition (keyboard and achievement notification).

Not documented: none of the thirteen mandatory subsystems. Vulkan behavioral
details beyond shared-boundary ownership are `NOT APPLICABLE` to the current
DLL.
