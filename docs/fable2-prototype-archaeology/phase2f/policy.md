# Phase 2F semantic-route policy v1

## Scope and evidence

This is a static, noncanonical transport audit. Source bytes, guest addresses, bounded native references, historical terminal identities and exact mapping edges are CONFIRMED observations. Gameplay/SDK lexical categorization is a PROBABLE contextual interpretation. No reference text is a function name. No grade grants runtime authorization, script ownership, content portability, mapping revision or canonical adoption.

All sources are authenticated before analysis through frozen Phase 2E trust roots and inherited bindings. Explicit `phase2e-v1` opt-in is mandatory and repeated in every output. Default Phase 2A behavior is not switched. No semantic output is an input to a mapping decision. All five unapproved ledger records, all 715 probable proposals and both same-name physics candidates remain excluded.

## Populations and lanes

The headline population is the exact 51,657 Phase 2B native-XREF terminal associations. Each appears once per lane, including the 9,605 associations without a safely assignable native owner. The 21,350 mapping-review records are aliases/subsets, not extra semantic votes. Anchors, instruction/data-pointer XREFs, registration calls, script inventories, preservation files, types, pointer runs, globals and boundary records have separately enumerated source identities. Domain records and pointer slots are never added to the headline terminal count. Multiple anchors can reference one complete literal or one function; exact aliases are retained and visible.

Historical H contains the independently recomputed original B policy and the original pure C semantic policy under each original frozen mapping. Their complete envelopes reproduce byte-for-byte. H-2A evaluates the original 15,299 mapping pairs with the new gates solely to isolate B00. It is historical evidence, not an approved enhanced view.

S contains 15,296 retained pairs after all three B00 suppressions. O is the exact opted-in 15,379-pair overlay. Cumulative lanes contain 15,313, 15,318, 15,378 and 15,379 pairs in B01, B02, B04, B05 order. Leave-one-batch-out lanes contain 15,362, 15,374, 15,319 and 15,378 pairs respectively. These counterfactuals do not mutate the approved overlay.

## Routes and dependencies

Owner routes are one Build-23→TU1 edge or two edges through the frozen retained September→Build-23 correspondence. No search or iterative expansion can invent an edge. Thus traversal depth is capped at two, build generations progress strictly, and a same numeric address in two builds is not a cycle or identity vote. A literal-consumer proof may additionally record its corresponding callee edge(s), at most four total semantic edges. Mapping prerequisite seeds remain separately recorded with their generation and frozen record hashes; each must predate the approved addition and remain included. No same-generation bootstrapping, held fallback or suppressed dependency is permitted.

Each terminal stores all available routes. The deterministic primary route prefers independently gated evidence, then an unreserved route, then fewer edges, then canonical JSON byte order. This tie-break does not turn path length into evidence strength. All alternative-route reservations remain in the terminal aggregate even when the primary route does not require them. New owner routing and newly enabled callee proof are counted separately. Jointly enabling mapping/batch contributions can overlap; exclusive cumulative first-enablement and leave-out necessity are not additive causal votes.

## Independent target gates

A positive literal-role proof requires a complete terminated native object, exact full identity, a compatible instruction/argument/width role, readonly storage, a start reference rather than an interior/empty/prefix pointer, and a corresponding included callee. Filtered/low-entropy references and common-helper observations cannot supply an independent vote. The canonicalized reference identity that established an approved mapping is explicitly non-independent. The frozen Phase 2D field, argument, return, control-flow and topology observations were already mapping gates, so their agreement is retained but not counted again.

At the same native role, a different complete literal is a conflict even at the same guest address. A matching literal at an incompatible corresponding role is also quarantined. Contradiction outranks similarity. Correlated strings in one function do not become multiple independent proofs. Registration roles require independently evidenced construction, callback, adapter, state, namespace, consumer and reachability links; literal transport alone resolves none of those missing obligations.

## Primary grades

| Grade | Gate |
|---|---|
| target-corroborated | Independent compatible native TU1 role/callee evidence; reservations remain attached |
| transported-context-reserved | Approved primary route depends on a reserved addition; no independent semantic proof |
| transported-context-unreserved | Unreserved approved primary route without independent target proof |
| target-unconfirmed | Closed route exists but target role/callee proof is insufficient |
| semantic-conflict-quarantined | Material target-native contradiction; no automatic mapping change |
| suppression-blocked | B00 removes the historical owner edge, with no included replacement |
| mapping-blocked | No approved owner route; no speculative fallback |
| ownership-or-boundary-blocked | Missing native owner or incompatible complete boundary |

Grades partition the headline population. A target-corroborated route may still be reserved. Transported grades also lack independent target confirmation; they are not stronger versions of target-unconfirmed. Domain `contextual-native-route` and `native-target-evidence` labels are separate non-accepting inventories, never headline proof grades.

## Categories and human review

Lexical predicates are published in `Fable2SemanticRoutes.category`: Xbox vector/intrinsic and explicit shader-compiler diagnostics are separated from native gameplay-field and Fable-context text. General platform strings are separate again. Ambiguous labels such as `UniqueID`, `Expression` and `Speed` remain unknown rather than receiving invented subsystem names. These lexical classes prioritize inspection; native text is not sufficient to establish a function's purpose. B04 publishes all-unique versus repeated-reference populations and common-helper versus non-common-helper reservations separately.

The exhaustive queue retains every newly connected terminal and every negative mapping result. The bounded tranche has at most eight owner/category groups, ranked by conflict precedence, independent game-context evidence, reserved game-context risk, unreserved game-context and registration/preservation relevance, with stable address ties. SDK wrappers are summarized separately. The human guide identifies an even smaller coherent first task; no bulk naming/adoption approval is requested.

## Non-propagation

Loose Lua identity does not prove retail use. Structural script pairing does not prove semantic or state identity. Hash comparisons honor the frozen Lua parser's terminator-excluded convention versus native terminator-included identity. E3/path presence is not runnable recovery. Pointer runs, access widths and type strings do not establish complete objects, constructors or vtables. Closure, coverage, ownership, Ghidra, indirect-target, renderer and historical-crash membership is context only. HammerCombat's comparator remains an internal code region. The six inherited blockers and historical generated-file mismatch remain unchanged.
