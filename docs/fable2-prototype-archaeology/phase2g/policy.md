# Phase 2G native semantic-proof policy v1

Phase 2G is a bounded, offline, noncanonical review of exactly three owner groups. It cannot change a mapping, reservation, function universe, function name, manifest, runtime, generated source, Ghidra database or proprietary asset. Every output carries `canonical_adoption: false`, `semantic_feedback_allowed: false`, `mapping_mutation_allowed: false` and `canonical_names_authorized: false`.

## Independence ledger

Each observation receives exactly one class:

- `mapping-consumed`: directly used to establish or approve a correspondence;
- `correlated-with-mapping`: derived from the same reference, helper or topology;
- `independent-target-native`: target behavior not used by mapping approval;
- `independent-cross-build-behavior`: corresponding behavior from a separately evidenced instruction/data relationship;
- `context-only`: interpretive context that cannot prove a role;
- `contradictory`: materially inconsistent with the proposed semantic role;
- `unresolved`: no safe classification is available.

Only a material, compatible, owned, non-circular observation in one of the two independent classes can satisfy an independent semantic-role gate. Strings passed through one helper, aliases of one XREF, canonicalized references, full-body similarity, mapped callees already used as Phase 2D gates, and duplicate-user topology cannot vote twice. Contradiction has review-trigger precedence but never mutates a Phase 2E mapping automatically.

## Role and reservation gates

Each packet receives one primary semantic disposition and separate mapping, reservation, role-label and canonical-name dispositions. A contextual label describes observed data flow; it is not a source-level or canonical function name. Constructor, vtable, complete-object, gameplay-owner, serialization and runtime-behavior claims require their own complete native obligations.

`internal-code-region-dependent` remains attached to Packet A. The comparator intervals remain internal code regions without exact `.pdata` ownership even when their bytes and behavior correspond. `single-independent-support-class` remains attached to Packets B and C unless a separately published owner release rule is met; Phase 2G itself does not remove it.

## Frozen inputs and isolation

Every analytical invocation rehashes the ten Phase 2F trust roots, all 32 ignored artifacts, Phase 2F implementation/documentation bindings, inherited Phase 1–2E inputs, both remote sets, the ReXGlue state and all fifteen libmspack identities. The explicit `phase2e-v1` overlay is mandatory, while the default consumer remains `closed-phase2a-default` at 15,299 mappings. Invalid or changed inputs fail without fallback.

Writes are physically confined to `docs/fable2-prototype-archaeology/phase2g/` and `out/prototype-archaeology/phase2g/`. JSON uses canonical key ordering and contains no time, locale, random or current-HEAD analytical input. Complete negative, contradictory and unresolved observations are retained.
