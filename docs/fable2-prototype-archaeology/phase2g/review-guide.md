# Phase 2G human review guide

No label below is a canonical function name. Phase 2G authorizes no naming or mapping mutation.

## Packet A

Provisional contextual label: **byte-state query with HammerCombat equality exclusion guard**.

Approve only as a behavior note. The owner returns zero when its nullable string equals `HammerCombat`; otherwise it follows nested state and returns a selected byte. Independent TU1 callers store or compare this byte at the same object's `+0x24`. Do not name the owner or generic inequality callee `HammerCombat`. Keep `internal-code-region-dependent` because the lexical comparator regions lack `.pdata` ownership.

## Packet B

Provisional contextual label: **keyed oxygen-field load plus 32-bit current-from-maximum initialization**.

The owner conditionally loads three opaque words through a keyed property helper and copies `+0x38` to `+0x34`. This is load/deserialization-style field population, not registration, outbound serialization, depletion or recovery arithmetic. No independent caller or downstream consumer was established. Keep `single-independent-support-class`.

## Packet C

Human-review candidate: **conditional keyed reward/world-map field materializer**.

The owner copies a two-word source handle, conditionally materializes opaque 32-bit values at `+0x20/+0x24` and a normalized Boolean-like byte at `+0x4D`, and has an independent TU1 caller that visits those exact fields through different typed visitor helpers. It does not grant rewards or update map markers.

Review trigger: Phase 2F attributes `RewardMoney` and `RewardRenown` to the first handle-resolver callee, but that body reads none of `r5/r6/r7`; the subsequent scalar helper consumes the key. `SetObjectiveTag` is also a rejected high-half alias, not a fourth semantic key. A later owner decision may correct that semantic attribution without altering the owner mapping. Keep `single-independent-support-class` unless a separate release rule is approved.
