## Exact explicit opt-in

```powershell
$pins = "docs/fable2-prototype-archaeology/phase2h/evidence/source-pins.json"
$decision = "docs/fable2-prototype-archaeology/phase2h/evidence/owner-decision.json"
$delta = "docs/fable2-prototype-archaeology/phase2h/evidence/semantic-correction-delta.json"
$view = "out/prototype-archaeology/phase2h/materialized-reviewed-semantic-view.json"

$pinsHash = (Get-FileHash -LiteralPath $pins -Algorithm SHA256).Hash
$decisionHash = (Get-FileHash -LiteralPath $decision -Algorithm SHA256).Hash
$deltaHash = (Get-FileHash -LiteralPath $delta -Algorithm SHA256).Hash
$viewHash = (Get-FileHash -LiteralPath $view -Algorithm SHA256).Hash

python -B tools/phase2h/Fable2ReviewedSemanticConsumer.py `
    --opt-in phase2h-v1 `
    --source-pins $pins --source-pins-sha256 $pinsHash `
    --decision $decision --decision-sha256 $decisionHash `
    --delta $delta --delta-sha256 $deltaHash `
    --view $view --view-sha256 $viewHash
```

Only those exact repository-relative paths, layer version, and current SHA-256 values are accepted. Partial, missing, stale, altered, over-broad, wrong-version, wrong-path, or wrong-hash selection exits with refusal and emits no successful fallback view.
